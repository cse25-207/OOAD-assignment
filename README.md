# Banking System

## Project Overview
This project is a Java-based Banking System developed for the CSE202 Object Oriented Analysis and Design with Java assignment.

The system allows customers to register, log in, open bank accounts, deposit money, withdraw money where permitted, check balances, view transaction history, and calculate monthly interest.

## Technologies Used
- Java 25
- JavaFX 26
- Maven
- H2 Database
- JDBC
- IntelliJ IDEA

## Main Features
- Individual and company customer registration
- Customer authentication
- Savings, Investment and Cheque accounts
- Deposits and withdrawals
- Account balance checking
- Monthly interest calculations
- Transaction history
- Database persistence
- Sample database records

## Object-Oriented Programming
The project demonstrates:
- Encapsulation
- Inheritance
- Abstraction
- Polymorphism
- Interfaces
- Method overriding and overloading

## Project Structure
- `src/main/java` – Java source code
- `database` – Database connection, initialization and DAO classes
- `pom.xml` – Maven project configuration

## Database
The system uses an H2 database through JDBC. Database tables store customer, account and transaction information.

Ten sample customers and accounts are inserted when the database is initialized.

## Running the Project
1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Allow Maven to load the dependencies.
4. Run the `BankingSystemGUI` main application.
